# Skills-Challenges
This repository contains different challenges to help students build robot programming skills. Challenges are broken up into steps - students are expected to complete steps in ascending numerical order. Solutions are available to help mentors/teachers understand the intent of a step and check students' work. Students should not reference solutions when working through a challenge.

Please see the [metadocs.md](/metadocs.md) file for information on the notation and structural breakdown of the challenge step docuemnts.

## Available challenges

- <b>Cone Drill (West Coast):</b> this is the foundational, new to robot programming challenge. Students learn how to program a differential drive robot, beginning with operating a single motor set on the drivetrain and progressing to writing an autonomous routine.
